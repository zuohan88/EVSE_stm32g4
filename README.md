# EVSE_stm32g4


1) This code is designed to work on MCU as EVSE and currently supports only CCS2 protocol. 
2) It tested with real EV car. Currently using din70121 protocol.
3) modified code from https://github.com/uhi22/ccs32clara. His code is built for EVCC.
4) TCP/IP stack have the minimum feature and code size that is only enough for CCS protocol.
